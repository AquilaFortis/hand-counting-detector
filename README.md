# dactylonomy-cnn
Convolutional Neural Network that determines which number is represented by a hand gesture (dactylonomy). Written using PyTorch.

## Acquiring Datset
You must manually download dataset from [Kaggle](https://www.kaggle.com/datasets/maneesh99/signs-detection-dataset) and extract the files into `./data` so you have:
* `./data/Signs_Data_Testing.h5`
* `./data/Signs_Data_Training.h5`


## Python Dependencies
* numpy
* h5py
* torch
* matplotlib
